## 価格・送料を変えるとき

1. `js/config.js` の `products` / `shipping` / `subscription` を変更
2. 画面に直接書いてある価格（`index.html` のプラン・FAQ、`guide.html`、`tokushoho.html`）も同じ値に
3. オンライン決済サーバーを使う場合は `../server.js` の `CATALOG` / `SHIPPING` も同じ値に

## 決済方法（`js/config.js` の `checkout.mode`）

### 1. `email`（現在の設定・準備不要）
確認画面で「メールで注文を送信する」を押すと、注文内容入りのメールが `info@kunioffice.jp` 宛てに開きます。
お客様が送信 → 店舗からお支払い方法をご案内、という流れです。電話・FAX注文も案内しています。

### 2. `stripe`（Stripe Payment Links・サーバー不要）
1. Stripe ダッシュボードで商品を3つ作成し、それぞれ Payment Link を発行
   - 定期便：**毎月の継続価格** 2,680円（数量調整を有効に）
   - 1箱：2,980円（数量調整を有効に）／送料は Stripe の配送料設定で
   - 3箱セット：8,340円
   - いずれも「配送先住所（日本）」「電話番号」を収集
   - 支払い後の遷移先：`https://playmark0227-svg.github.io/kunioffice/wakaba/thanks.html?status=paid`
2. 発行したURLを `stripePaymentLinks` に貼り、`mode: 'stripe'` に変更
   - カート内が1種類の商品のときに Stripe へ進みます。複数種類の場合はメール注文に切り替わります。

### 3. `endpoint`（`server.js` で Stripe Checkout・カートをまとめて決済）
1. リポジトリ直下の `server.js` を Render / Railway / Fly.io などにデプロイ
2. 環境変数を設定（値は `.env.example` 参照。**シークレットキーは絶対に公開しない**）
3. `checkout.endpoint` にデプロイ先の `https://…/api/checkout` を入れ、`mode: 'endpoint'` に変更

`server.js` は商品IDと数量だけを受け取り、**価格・送料はサーバー側で計算**します（改ざん対策）。

## CM の差し替え
`media/cm15.mp4`（H.264）・`media/cm15.webm`（VP9）・`media/cm15-poster.jpg` を置き換えるだけです。
映像にAI生成のイメージ映像を含む場合は、CMセクションの注記（`cm-note`）を残してください。

## 公開前に販売者へ確認すること
現在は既存サイトの情報をもとに仮で入れています。正式販売の前に必ずご確認ください。

- [ ] 販売業者名・**運営統括責任者のフルネーム**（特商法表記は現在「代表 高桑」）
- [ ] 商品表示：名称／原材料名／内容量（3g×30包）／賞味期限（製造日より1年）／保存方法
- [ ] 価格（1箱2,980円・3箱8,340円・定期便2,680円）と送料（全国一律500円・5,000円以上無料）
- [ ] 発送までの日数（1〜3営業日）・お届け時間帯指定の可否
- [ ] お支払い方法（現在は「受付後にメールで案内」）
- [ ] 定期便の条件（毎月1回・回数縛りなし・次回お届け予定日の7日前までに連絡で休止／解約）
- [ ] 返品・交換の条件（不良品は到着後7日以内・当店負担で交換）
