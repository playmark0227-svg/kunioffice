作業の前に、この3つだけ守ってください

  1. 作業前に、フォルダを丸ごとコピーしてバックアップを取っておく（失敗しても元に戻せます）
  2. 写真は「同じファイル名」で上書きするだけで差し替わります（HTMLを触る必要はありません）
  3. 文章は「文字だけ」書き換える。< と > で囲まれた部分（タグ）は消したり変えたりしない

もくじ

  1. フォルダの中身
  2. 写真を差し替える（写真一覧つき）
  3. 文章を直す
  4. 実績を追加・削除する
  5. パソコンで確認する
  6. ホームページに反映（公開）する
  7. お問い合わせフォームについて
  8. オンラインショップ（若葉のしずく）
  9. うまくいかないとき

2写真を差し替える

手順（同じ名前で上書きするだけ）

  1. 差し替えたい写真を、下の「写真一覧」で探し、ファイル名を確認します（例：service-photo.jpg）。
  2. 新しい写真のファイル名を、そのファイル名と1文字も違わない名前に変えます。
  3. その写真を images フォルダに入れ、「置き換えますか？」と聞かれたら「置き換える」を選びます。
  4. 5章の方法でパソコンで確認し、6章の方法で公開します。

ポイント：1枚の写真が2か所に出ることがあります

たとえば service-photo.jpg を差し替えると、「事業内容ページ」と「トップページのServices」の両方が新しい写真に変わります。どこに出るかは写真一覧の「表示される場所」で確認できます。

写真の大きさ・向き

項目おすすめ

写真は枠に合わせて自動で中央を切り抜いて表示されます。端に写っているものは切れることがあるので、見せたいものは写真の中央に置いてください。

ファイル名の注意

  • 大文字・小文字も区別されます。Service-Photo.JPG や service-photo.jpeg は別の名前として扱われ、表示されません。
  • パソコンの設定で拡張子（.jpg）が見えないと、名前を変えたときに service-photo.jpg.jpg になってしまうことがあります。
    Windows は「表示」→「ファイル名拡張子」にチェック、Mac は Finder の「設定」→「詳細」→「すべてのファイル名拡張子を表示」をオンにすると確認できます。

3文章を直す

使うソフト

Windows

「メモ帳」で開けます。ファイルを右クリック →「プログラムから開く」→「メモ帳」。

Mac

「テキストエディット」で開くと見た目が崩れて表示されるため、次の Visual Studio Code をおすすめします。

おすすめは無料の Visual Studio Code（Windows・Mac 両方あり）です。文字の色分けで「タグ」と「文章」の区別がつきやすく、全ページまとめての置き換えもできます。

手順

  1. 直したいページのファイルを開きます（下の表を参照）。
  2. Ctrl + F（Mac は ⌘ + F）を押し、今ホームページに出ている文章の一部を入力して探します。
  3. 見つかった文章の文字だけを書き換えます。
  4. 上書き保存します（Ctrl + S／Mac は ⌘ + S）。文字コードを聞かれたら UTF-8 のまま保存してください。
  5. 5章の方法でパソコンで確認します。

事業内容services.html
実績works.html

お問い合わせcontact.html

書き換えてよい所・いけない所

例：事業内容ページ「写真撮影」の説明文を直す場合

変更前

<p class="service-description">
    プロフェッショナルな技術と経験で、あらゆるシーンの撮影に対応いたします。
    商品撮影、イベント撮影、店舗撮影など、お客様のニーズに合わせた最適な撮影プランをご提案します。
</p>

変更後（黄色の文字の部分だけ変える）

<p class="service-description">
    標津町を中心に、商品・店舗・イベントの撮影をお受けしています。
    出張撮影もご相談ください。
</p>

青い文字（タグ）は変えない

  • <p class="..."> や </p> のような、< と > で囲まれた部分は消したり変えたりしないでください。表示が崩れます。
  • 文中で改行したいときは、改行したい場所に <br> と入れます。
  • &amp; は「&」記号の書き方です。そのまま残してください。

箇条書きの項目を増やす・減らす

事業内容ページの「サービス内容」などの箇条書きは、<li>〜</li> の1行が1項目です。1行まるごとコピーして下に貼り付け、文字を書き換えれば項目が増えます。減らすときは1行まるごと消します。

<li>商品撮影（物撮り）</li>
<li>イベント撮影</li>
<li>ドローン空撮</li>   ← コピーして追加した行

住所・電話番号・メール・営業時間を変えるとき

これらは各ページの下の部分（フッター）など、複数のファイルにそれぞれ書かれています。1つのファイルだけ直すと、ページによって違う番号が出てしまいます。

Visual Studio Code なら一度に置き換えられます

  1. Visual Studio Code の「ファイル」→「フォルダーを開く」で、受け取ったフォルダ全体を開きます。
  2. Ctrl + Shift + H（Mac は ⌘ + Shift + H）で「フォルダーで置換」を開きます。
  3. 上の欄に古い番号、下の欄に新しい番号を入れ、見つかった場所を確認してから「すべて置換」を押します。

4実績を追加・削除する

実績ページ（works.html）の実績は、1件ごとに次のような10行のかたまりで書かれています。

<div class="work-item" data-category="photo">
    <div class="work-image">
        <img src="images/work-event.jpg" alt="地域イベント撮影">
    </div>
    <div class="work-details">
        <span class="work-category">写真撮影</span>
        <h3>地域イベント撮影</h3>
        <p>標津町の祭りイベントの記録撮影。躍動感のある瞬間を捉えました。</p>
    </div>
</div>

追加する

  1. 写真に新しいファイル名を付けて images フォルダに入れます。名前は半角の英数字とハイフンだけ（例：work-shibetsu-festival.jpg）。日本語や空白は使わないでください。
  2. works.html を開き、同じ種類の実績のかたまり（<div class="work-item" の行から数えて10行目の </div> まで）をまるごとコピーし、そのすぐ下に貼り付けます。
  3. 貼り付けたかたまりの黄色の部分（写真のファイル名・タイトル・説明文・種類）を書き換えます。
  4. 種類（data-category="..." と表示名）は、下の表の組み合わせのどれかにします。実績ページ上部の絞り込みボタンはこの値で動きます。
data-category="..." に入れる値表示名（work-category に入れる文字）
photo写真撮影
print印刷物
video映像制作
signboard看板
goodsオリジナルグッズ

削除する

消したい実績のかたまりを、<div class="work-item" の行から数えて10行目の </div> まで、まるごと消します。途中だけ消したり、行数がずれたりすると表示が崩れます。

トップページの「Works」（6枠）

トップページの実績紹介は index.html に書かれていて、写真は実績ページと同じファイル（★印）を使っています。実績ページの写真を上書きすると、トップページも一緒に変わります。トップに出す実績そのものを入れ替えたいときは、index.html の class="work-tile" の部分の写真のファイル名とタイトルを書き換えてください。

5パソコンで確認する

  1. フォルダの中の index.html をダブルクリックすると、インターネットに公開する前の状態をブラウザで見られます。
  2. 変更したページを開いて、写真や文章が正しく出ているか確認します。スマホでの見え方は、ブラウザの幅を狭くすると確認できます。
  3. 変わっていないときは、再読み込み（Ctrl + Shift + R／Mac は ⌘ + Shift + R）をしてください。

パソコンで開いたときは、地図やお問い合わせなど、一部インターネットにつながっている部分の動きが本番と違うことがあります。

6ホームページに反映（公開）する

パソコンの中のファイルを直しただけでは、インターネット上のホームページは変わりません。次のどちらかの方法で反映します。

公開中のホームページ：https://playmark0227-svg.github.io/kunioffice/

方法A：変更したファイルを ViFight に送る（かんたん）

  1. 変更した写真・ファイルをまとめて ViFight（久保）に送ります（メール添付や大容量ファイル送信サービスなど）。
  2. ViFight 側でホームページに反映し、ご連絡します。

方法B：GitHub（ギットハブ）で直接反映する

ホームページのデータは GitHub というサービスに保管されていて、ここに変更を保存すると1〜2分で自動的にホームページに反映されます。ViFight から GitHub の編集権限を受け取ったあとに使える方法です。

写真を差し替える

  1. GitHub にログインし、https://github.com/playmark0227-svg/kunioffice を開きます。
  2. images フォルダをクリックします。
  3. 右上の「Add file」→「Upload files」を押します。
  4. 差し替える写真（一覧と同じファイル名にしたもの）をドラッグ＆ドロップします。
  5. 下の緑のボタン「Commit changes」を押します。

文章を直す

  1. 直したいファイル（例：services.html）をクリックします。
  2. 右上の鉛筆マーク（Edit this file）を押します。
  3. 3章と同じ要領で文字だけ書き換えます。
  4. 右上の「Commit changes...」→ 出てきた画面の「Commit changes」を押します。

反映されたか確認するには

1〜2分たってからホームページを開き、再読み込みしてください。GitHub の「Actions」タブで、いちばん上に緑のチェックが付いていれば反映完了です。赤いバツが付いたときは、ViFight にご連絡ください。

GitHub には変更の履歴がすべて残るので、失敗してもあとから元に戻せます。

7お問い合わせフォームについて

お問い合わせページのフォームで「メールで送信する」を押すと、お客様のパソコン・スマホのメールアプリが、入力内容が入った状態で開きます。お客様がそのまま送信すると、info@kunioffice.jp にメールが届きます。

送り先のメールアドレスを変えるときは、js/main.js を開いて CONTACT_EMAIL で検索し、const CONTACT_EMAIL = 'info@kunioffice.jp'; の ' と ' の間を書き換えてください。

8オンラインショップ（若葉のしずく）

ショップは wakaba フォルダの中にあり、ページの構成は KUNI OFFICE のページと同じです。写真は wakaba/images フォルダを同じ名前で上書きすれば差し替わります（写真一覧の最後を参照）。

変えたいこと直すファイル
価格・送料・定期便の条件wakaba/js/config.js（カートの計算に使う値）と、ページに書いてある価格（wakaba/index.html・wakaba/guide.html・wakaba/tokushoho.html、KUNI OFFICE トップの index.html の「Online Shop」）の両方
商品説明・飲み方・よくある質問wakaba/index.html
送料・お届け・返品の説明wakaba/guide.html
販売者・連絡先などの法律上の表記wakaba/tokushoho.html

ご注文の受け取り方

今は「お客様のメールアプリが、注文内容が入った状態で開き、info@kunioffice.jp に送られる」方式です。注文メールが届いたら、お支払い方法とお届け予定日をお客様にメールでご案内してください。クレジットカード決済を使いたい場合は ViFight にご相談ください。

販売前にご確認ください

「特定商取引法に基づく表記」（wakaba/tokushoho.html）の運営統括責任者は、いま「代表 高桑」とだけ書かれています。フルネームでの記載が必要なため、お名前を書き足してください。商品の表示（内容量・賞味期限など）、送料、発送日数、返品の条件も、実際の内容と合っているかご確認ください。

9うまくいかないとき

こんなとき確認すること
写真を入れたのに表示されないファイル名が一覧と完全に同じか（大文字・小文字、.jpg と .jpeg の違い、.jpg.jpg になっていないか）。iPhone の HEIC 形式ではないか。
古い写真・古い文章のまま再読み込み（Ctrl + Shift + R）。公開中のホームページの場合は、反映に1〜2分かかります。
ページの見た目が崩れたタグ（< > の部分）を消していないか。直したファイルをバックアップのものに戻すと元に戻ります。
文字化けした保存するときの文字コードが UTF-8 になっているか。

わからないことや、大きな変更（ページの追加・デザインの変更など）は、ViFight（久保）までご連絡ください。
