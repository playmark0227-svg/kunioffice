管理画面

KUNI OFFICE・若葉のしずくのホームページを編集します。

サイト管理者（ViFight）から受け取った文字列を貼り付けてください。

安全のため、ふだんはオフのままがおすすめです。アクセスキーは iPhone やパソコンの「パスワード」に保存しておくと、次から簡単に入力できます。

アクセスキーの作り方（サイト管理者向け）
  1. GitHub にログインし、右上のアイコン → Settings を開く
  2. 左メニューの一番下 Developer settings → Personal access tokens → Fine-grained tokens
  3. Generate new token を押す
  4. Repository access: Only select repositories → kunioffice を選ぶ
  5. Permissions: Contents = Read and write、Actions = Read-only
  6. Expiration: 1年（期限が来たら作り直す）
  7. Generate token を押す → 表示された文字列を担当者に安全に渡す
  8. 担当者の iPhone・パソコンの「パスワード」に保存してもらう（GitHub では二度と表示されません。iPhone の Safari は7日ほど使わないと「記憶する」の内容を消すことがあります）

この文字列があればサイトを書き換えられます。メールやチャットに残さず、直接お渡しください。

このサイトは playmark0227-svg.github.io のほかの GitHub Pages のサイトと同じオリジンにあります。「このブラウザに記憶する」をオンにすると、同じブラウザで開いたそれらのサイトのスクリプトからも読み取れてしまうため、既定ではオフにしています。独自ドメイン（例: kunioffice.jp）で公開すると、この心配はなくなります。

管理画面は検索エンジンには表示されません。
