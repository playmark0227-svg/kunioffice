管理画面

For site admin

アクセスキーの用意

高桑様の iPhone で管理画面を使えるようにする、サイト管理者（ViFight）用のページです。パソコンで GitHub にログインした状態で、上から順に進めてください（約3分）。

  1. 01

    GitHub でアクセスキーを作る

    名前・説明・期限（1年）・権限が入力済みの画面が開きます。

    GitHubでアクセスキーを作る

    開いた画面で、この4つだけ操作してください。

    1. 「Repository access」で Only select repositories を選ぶ
    2. 「Select repositories」で kunioffice を選ぶ
    3. いちばん下の Generate token を押す確認が出たら、もう一度 Generate token
    4. 表示された github_pat_… をコピーする

    キーは GitHub で一度しか表示されません。高桑様に渡し終わるまで、GitHub の画面は閉じないでください。

    入力済みの内容を確かめる
    Token name
    KUNI OFFICE 管理画面
    Resource owner
    playmark0227-svg
    Expiration
    366 days（1年後 まで）
    Permissions
    Contents：Read and write
    Actions：Read-only
    Metadata：Read-only（自動）
  2. 02

    キーを確認する

    このサイトを編集できるキーか、GitHub に問い合わせるだけです。キーはどこにも保存しません。

  3. 03

    高桑様の iPhone に入れる（1回だけ）

    ②で確認できると、ここに手順が表示されます。

    1. iPhone の Safari で、このURLを開く
      https://playmark0227-svg.github.io/kunioffice/admin/
      このURLは LINE やメールで送っても大丈夫です（キーは入っていません）。
    2. 共有ボタン（□に↑）→「ホーム画面に追加」→「追加」 共有ボタンが見当たらないときは「…」の中にあります。「Webアプリとして開く」が出たら、オンのまま。
    3. ホーム画面の「KUNI管理」アイコンから開く Safari の画面ではなく、アイコンから開いた画面で入れてください（そのほうがキーが消えにくくなります）。
    4. アクセスキーを1回だけ貼り付けて「管理画面を開く」 「この端末に記憶する」はオンのまま。
    5. 次からは、アイコンを押すだけで使えます。

    キーの渡し方

    直接会って入力するのがいちばん安全です。離れているときは AirDrop か、iPhone の「パスワード」の共有で。LINE・メールなどのチャットには残さないでください。

    なくしたとき・漏れたかもしれないとき

    GitHub の Fine-grained tokens でこのキーを削除（Revoke）して、このページで作り直してください。

    期限は1年

    1年後 ごろに切れます。切れると管理画面に「期限が切れたか、無効になりました」と出るので、このページでもう一度作って、同じように入れ直してください。

    パソコンでも使うときは、管理画面を開いて同じキーを貼り付けるだけです。

管理画面へ

メモ：記憶したキーは、その端末のこのサイト用の保存領域に入ります。playmark0227-svg.github.io のほかの GitHub Pages のサイトとは保存領域が共通なので、そちらに外部のスクリプトを入れるときは気をつけてください（独自ドメインにすると分けられます）。
